Qwen3.8-27B: MTP3, EAGLE4, DFlash2 and OpenJet

Retain baseline MTP3. It led the measured NVFP4 AgentX c32 series at 171.19 output tokens/s. No tested configuration demonstrated a better overall AgentX result. The experiment has ended; the tuning Pod was deleted and production was unchanged.

One 96GB RTX PRO 6000 Blackwell Server Edition, one model worker. NVFP4 target: nvidia/Qwen3.8-27B-NVFP4, revision 482ca0f3832238542f8f5295dde86b5f22711d80. These are single-worker serving measurements, not distributed scheduling or a public API capacity guarantee.

OpenJet and Unsloth GGUF, separate comparison

Unsloth UD-Q4_K_XL uses a different quantization and engine. OpenJet executes one request at a time even when AgentX requests 32 sessions. Its high per-stream decode speed does not establish high concurrent aggregate throughput. The trial passed ten quality checks and four long-context canaries; complete API conformance was not established.
